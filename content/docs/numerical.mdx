When no elementary antiderivative is available, approximate the integral by fitting shapes to small subintervals.

## Rules and weights

With $\Delta x=(b-a)/n$, the trapezoidal rule uses endpoint weight $1$ and interior weight $2$. Simpson's rule requires even $n$, uses weights $1,4,2,4,\ldots,4,1$, and multiplies by $\Delta x/3$.

For $\int_1^3 1/x\,dx$ with $n=4$, list the five function values first, then insert the weights. Simpson's result is close to $\ln3$; compare only after the weighted sum is complete.

## Error and shape

The trapezoidal error is controlled by a bound on $\lvert f''\rvert$, while Simpson's error uses a bound on $\lvert f^{(4)}\rvert$. Doubling $n$ reduces trapezoidal error by about $4$ and Simpson error by about $16$.
